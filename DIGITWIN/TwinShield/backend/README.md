# TwinShield Backend Service

Spring Boot backend service for the TwinShield platform.

## Responsibilities
- Employee profile and role management
- Authentication and session tracking
- Bank domain APIs (Customer search, Transaction queries, Accounts)
- Security event emitter to ML engine

## Tech Stack
- **Language**: Java 17
- **Framework**: Spring Boot 3.2.x
- **Build Tool**: Maven

## Running the Application
```bash
mvn clean spring-boot:run
```
